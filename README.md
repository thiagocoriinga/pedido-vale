# PEDIDOVALE • PAINEL SUPER ADMIN MASTER 👑

Este e o projeto independente da sua plataforma de delivery para gerenciar todos os restaurantes, assinaturas e mensalidades da regiao.

### Arquivos inclusos:
- **index.html**: Painel grafico Super Admin completo.
- **superadmin.js**: Motor de gestao de lojas, bloqueios e cobrancas no WhatsApp.
- **schema_multitenant.sql**: Script SQL para o banco de dados Supabase.

Abra esta pasta em uma nova janela para continuarmos o desenvolvimento focado na sua plataforma!
